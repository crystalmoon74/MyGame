# 🎵 가요 타임머신 퀴즈

1990~2020년 히트 가요의 30초 미리듣기를 듣고 **가수와 제목**을 맞추는 웹 게임입니다.

▶ **플레이하기: https://crystalmoon74.github.io/MyGame/**

## 기능
- 시대 선택: 90년대 / 2000년대 / 2010년대 (여러 개 선택 가능)
- 모드: 객관식(4지선다), 주관식(가수 + 제목 입력, 오타는 조금 봐줌, 반만 맞혀도 부분 점수)
- 빨리 맞힐수록 높은 점수, 힌트(발표 연도 → 초성) 사용 시 감점
- 모드별 최고 기록 저장

## 참고
- 음원은 Apple iTunes Search API의 공식 30초 미리듣기를 실시간으로 불러오며, 이 저장소에는 음원 파일이 포함되어 있지 않습니다.
- iTunes에서 미리듣기를 찾지 못한 곡은 자동으로 건너뜁니다.
- 별도 설치 없이 `index.html` 하나로 동작합니다.
